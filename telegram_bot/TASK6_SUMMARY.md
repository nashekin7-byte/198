### 3. Новые функции

#### `broadcast_start()` (строки 596-636)
- Проверяет права администратора
- Получает количество оплативших клиентов
- Показывает предупреждение с количеством получателей
- Просит отправить материал для рассылки
- Переходит в состояние `WAITING_BROADCAST`

#### `broadcast_send_material()` (строки 638-796)
- Принимает материал от админа (фото, видео, документ, текст)
- Показывает сообщение "⏳ Отправляю материалы..."
- Получает всех оплативших клиентов
- Отправляет материал каждому пользователю:
  - Определяет тип материала
  - Отправляет с соответствующей подписью
  - Добавляет задержку 0.05 сек между отправками
  - Обновляет прогресс каждые 5 пользователей
  - Обрабатывает ошибки (заблокировавшие клиенты)
- Показывает детальную статистику после завершения
- Удаляет прогресс-сообщение

#### `cancel_broadcast()` (строки 798-817)
- Отменяет операцию рассылки в любой момент
- Возвращает в админ-панель

### 5. Регистрация ConversationHandler (`main.py`, строки 857-871)
```python
broadcast_handler = ConversationHandler(
    entry_points=[MessageHandler(filters.TEXT & filters.Regex("^📢 Рассылка всем$"), broadcast_start)],
    states={
        WAITING_BROADCAST: [
            MessageHandler(
                filters.PHOTO | filters.VIDEO | filters.Document.PDF | filters.TEXT,
                broadcast_send_material
            )
        ],
    },
    fallbacks=[CommandHandler("cancel", cancel_broadcast)],
)

app.add_handler(broadcast_handler)
```

## Использование

1. Администратор нажимает кнопку "📢 Рассылка всем" в админ-панели
2. Бот показывает количество оплативших клиентов
3. Администратор отправляет материал (фото, видео, документ или текст)
4. Бот отправляет материал всем оплатившим клиентам
5. Показывает прогресс и статистику
6. Возвращает в админ-панель
