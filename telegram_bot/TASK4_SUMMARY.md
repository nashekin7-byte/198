### 5. Регистрация обработчиков

**Файл:** `main.py` (строки 346-357)

```python
# Обработчики для клиентов
app.add_handler(CommandHandler("start", start))
app.add_handler(CommandHandler("status", status_command))

# Обработчики для администратора
app.add_handler(CommandHandler("admin", admin_command))

# Универсальный обработчик сообщений для кнопок
app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, handle_message))
app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, handle_admin_message))
```

**Порядок регистрации важен:**
1. Команды (start, status, admin)
2. Обработчики текстовых сообщений для клиентов
3. Обработчики текстовых сообщений для админа

## 🔧 Технические детали

### Параметры функции:

**`show_clients_list(update, context)`**
- `update`: Telegram Update объект
- `context`: Telegram Context объект
- Возвращает: None (отправляет сообщение через bot.send_message)

### Используемые функции из database.py:

1. **`get_all_users()`**
   - Возвращает: List[Dict] с данными всех пользователей
   - Формат: `{'user_id', 'username', 'first_name', 'paid', 'paid_date', 'materials_sent', 'created_at'}`

### Лимиты Telegram:

- Максимальная длина сообщения: 4096 символов
- Используем лимит: 4000 символов (с запасом)
- Парсинг: Markdown для backticks
