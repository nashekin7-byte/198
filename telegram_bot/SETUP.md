# Настройка и запуск бота

## Шаг 1: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Получите токен бота (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Получение вашего Telegram ID (для администратора)

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение
3. Бот отправит вам ваш ID (например: `123456789`)

## Шаг 3: Настройка main.py

Откройте файл `main.py` и замените следующие значения:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN"  # Замените на токен от @BotFather
ADMIN_ID = 123456789  # Замените на ваш ID от @userinfobot
```

## Шаг 4: Установка зависимостей

```bash
cd telegram_bot
pip install -r requirements.txt
```

## Шаг 5: Запуск бота

```bash
python main.py
```

Бот автоматически создаст необходимые директории и файлы:
- `bot_data/bot.db` - база данных SQLite
- `logs/bot.log` - файл логов

## Проверка работы

1. Найдите вашего бота в Telegram по имени, которое вы указали при создании
2. Отправьте команду `/start`
3. Вы должны увидеть приветственное сообщение и клавиатуру с кнопками

## Команды для клиентов

- `/start` - Начало работы с ботом
- `/status` - Проверка статуса оплаты
- Кнопка "💳 Оплатить" - Получение реквизитов для оплаты
- Кнопка "📊 Мой статус" - Проверка статуса

## Логи

Все действия пользователей и ошибки логируются в файл `logs/bot.log`.

Для просмотра логов в реальном времени:
```bash
tail -f logs/bot.log
```

## Структура базы данных

Таблица `users`:
- `user_id` - ID пользователя в Telegram (PRIMARY KEY)
- `username` - Имя пользователя в Telegram
- `first_name` - Имя пользователя
- `paid` - Статус оплаты (0 или 1)
- `paid_date` - Дата и время оплаты
- `materials_sent` - Статус отправки материалов (0 или 1)
- `created_at` - Дата регистрации пользователя

## Остановка бота

Для остановки бота нажмите `Ctrl+C` в терминале.
