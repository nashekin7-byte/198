# Шаблоны сообщений бота

Этот файл содержит все текстовые сообщения, которые бот отправляет пользователям.

## Приветственное сообщение (/start)

```
👋 Добро пожаловать в наш сервис, {first_name}!

Здесь вы можете:
✅ Оплатить доступ и получить эксклюзивные материалы
✅ Проверить статус вашей оплаты

Выберите действие из меню ниже.
```

**Переменные:**
- `{first_name}` - имя пользователя из Telegram

## Реквизиты для оплаты (кнопка "💳 Оплатить")

### Если пользователь уже оплатил:

```
✅ Вы уже произвели оплату!

Материалы будут отправлены вам вскоре.
Проверьте статус командой /status
```

### Если пользователь еще не оплатил:

```
💳 РЕКВИЗИТЫ ДЛЯ ОПЛАТЫ

Сумма: 1500 ₽

Номер карты:
2200 1234 5678 9012

После оплаты администратор проверит платеж и отправит вам материалы.

⚠️ Ваш ID для связи с администратором:
`{user_id}`
(можно скопировать)

Если у вас возникли вопросы - напишите администратору.
```

**Переменные:**
- `{user_id}` - ID пользователя в Telegram

**Форматирование:**
- ID пользователя выводится в моноширинном шрифте (backticks в Markdown)

## Проверка статуса (/status или кнопка "📊 Мой статус")

### Вариант 1: Пользователь не оплатил

```
❌ СТАТУС ОПЛАТЫ: Не получена

Для получения доступа оплатите 1500 ₽
Используйте кнопку "💳 Оплатить" для просмотра реквизитов.
```

### Вариант 2: Оплата получена, материалы в процессе

```
✅ СТАТУС ОПЛАТЫ: Получена

⏳ СТАТУС МАТЕРИАЛОВ: В процессе обработки

Администратор проверит платеж и отправит вам материалы в ближайшее время.
```

### Вариант 3: Всё готово

```
✅ СТАТУС ОПЛАТЫ: Получена
✅ СТАТУС МАТЕРИАЛОВ: Отправлены

Спасибо за покупку! Материалы успешно отправлены вам.
Если у вас возникли проблемы с доступом - напишите администратору.
```

## Сообщения об ошибках

### Общая ошибка при команде /start

```
❌ Произошла ошибка. Попробуйте позже.
```

### Ошибка при обработке платежа

```
❌ Произошла ошибка при обработке платежа.
```

### Ошибка при проверке статуса

```
❌ Произошла ошибка при проверке статуса.
```

## Клавиатура

Основная клавиатура содержит 2 кнопки в одном ряду:

```
[💳 Оплатить] [📊 Мой статус]
```

**Параметры:**
- `resize_keyboard=True` - автоматическое масштабирование кнопок

## Примечания по локализации

Все сообщения на русском языке. При необходимости добавления других языков:

1. Создайте отдельный файл для каждого языка (например, `messages_en.py`, `messages_ru.py`)
2. Определите все текстовые константы в этих файлах
3. Загружайте нужный файл в зависимости от языка пользователя (можно хранить в БД)

## Примечания по изменению текстов

При изменении текстов сообщений:

1. Сохраняйте структуру и форматирование (эмодзи, отступы)
2. Обновляйте этот файл после изменений
3. Убедитесь, что все переменные (`{user_id}`, `{first_name}`) корректно подставляются
4. Проверьте корректность Markdown форматирования (особенно для backticks)
