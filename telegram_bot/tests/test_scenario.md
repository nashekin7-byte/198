# Сценарий тестирования бота

1. **Команда /start**
   - Бот должен приветствовать пользователя.
   - Пользователь должен быть добавлен в БД.

2. **Проверка оплаты**
   - Пользователь нажимает кнопку оплаты.
   - После успешной оплаты статус в БД меняется на `paid = 1`.

3. **Получение материалов**
   - Оплативший пользователь запрашивает материалы.
   - Бот проверяет статус оплаты в БД.
   - Бот отправляет материалы и устанавливает `materials_sent = 1`.
