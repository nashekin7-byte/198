# Telegram Bot

Бот для управления доступом к материалам после оплаты.

## Структура проекта

- `main.py`: Основной файл запуска бота.
- `database.py`: Модуль для работы с базой данных SQLite.
- `config.py`: Конфигурационные данные и токены.
- `payments.py`: Модуль для интеграции платежных систем.
- `bot_data/`: Директория для хранения файла базы данных.
- `logs/`: Директория для хранения логов.

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` и добавьте необходимые переменные окружения.
4. Запустите бота:
   ```bash
   python main.py
   ```
