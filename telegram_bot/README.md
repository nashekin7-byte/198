# Telegram Bot для управления доступом

Бот для управления доступом к материалам после оплаты.

## Возможности

✅ **Для клиентов:**
- Просмотр реквизитов для оплаты
- Проверка статуса оплаты и отправки материалов
- Удобная клавиатура с кнопками

✅ **Для администраторов** (будет реализовано в следующих задачах):
- Просмотр всех пользователей
- Отметка оплат
- Отправка материалов
- Массовая рассылка

## Структура проекта

### Основные файлы:
- **`main.py`** - Основной файл бота с обработчиками команд для клиентов
- **`database.py`** - Модуль для работы с базой данных SQLite
- **`config.py`** - Конфигурационные данные и токены (пока пусто)
- **`payments.py`** - Модуль для интеграции платежных систем (будет реализован позже)
- **`requirements.txt`** - Список зависимостей Python

### Директории:
- **`bot_data/`** - Хранение файла базы данных (`bot.db`)
- **`logs/`** - Хранение логов бота (`bot.log`)
- **`tests/`** - Тестовые сценарии

### Документация:
- **`SETUP.md`** - Пошаговая инструкция по настройке и запуску бота
- **`USAGE_EXAMPLE.md`** - Примеры использования и тестовые сценарии
- **`MESSAGE_TEMPLATES.md`** - Все шаблоны текстовых сообщений бота
- **`test_logic.py`** - Скрипт для тестирования логики без Telegram API

## Быстрый старт

### 1. Установка зависимостей

```bash
cd telegram_bot
pip install -r requirements.txt
```

### 2. Настройка бота

1. Получите токен от [@BotFather](https://t.me/BotFather) в Telegram
2. Получите ваш ID от [@userinfobot](https://t.me/userinfobot)
3. Откройте `main.py` и замените:
   ```python
   BOT_TOKEN = "YOUR_BOT_TOKEN"  # Ваш токен
   ADMIN_ID = 123456789  # Ваш Telegram ID
   ```

### 3. Тестирование логики (без Telegram)

```bash
python test_logic.py
```

### 4. Запуск бота

```bash
python main.py
```

Подробная инструкция: см. **[SETUP.md](SETUP.md)**

## Команды для клиентов

- **`/start`** - Начало работы с ботом, показ главного меню
- **`/status`** - Проверка статуса оплаты и материалов
- **Кнопка "💳 Оплатить"** - Получение реквизитов для оплаты
- **Кнопка "📊 Мой статус"** - Проверка статуса (аналогично `/status`)

## Технические детали

### База данных

SQLite база с таблицей `users`:

| Поле | Тип | Описание |
|------|-----|----------|
| `user_id` | INTEGER (PK) | ID пользователя в Telegram |
| `username` | TEXT | Имя пользователя (@username) |
| `first_name` | TEXT | Имя пользователя |
| `paid` | BOOLEAN | Статус оплаты (0/1) |
| `paid_date` | TIMESTAMP | Дата и время оплаты |
| `materials_sent` | BOOLEAN | Статус отправки материалов (0/1) |
| `created_at` | TIMESTAMP | Дата регистрации |

### Логирование

Все действия логируются в `logs/bot.log`:
- Информационные сообщения (INFO) - команды пользователей
- Предупреждения (WARNING) - повторные регистрации
- Ошибки (ERROR) - исключения и проблемы

Просмотр логов в реальном времени:
```bash
tail -f logs/bot.log
```

### Зависимости

- `python-telegram-bot>=20.0` - Библиотека для работы с Telegram Bot API
- `python-dotenv` - Загрузка переменных окружения
- `requests` - HTTP-запросы (для будущей интеграции платежей)

## Статусы пользователя

1. **Не оплатил** - `paid=False`, `materials_sent=False`
2. **Оплатил, материалы в обработке** - `paid=True`, `materials_sent=False`
3. **Материалы отправлены** - `paid=True`, `materials_sent=True`
