# Примеры использования бота

## Сценарий 1: Новый пользователь

### Шаг 1: Пользователь запускает бота

**Действие:** Пользователь нажимает кнопку "Start" или отправляет `/start`

**Что происходит:**
1. Бот добавляет пользователя в базу данных
2. Отправляет приветственное сообщение
3. Показывает клавиатуру с кнопками "💳 Оплатить" и "📊 Мой статус"

**Логи:**
```
INFO - User 123456789 (@username) started the bot
```

---

### Шаг 2: Пользователь хочет оплатить

**Действие:** Пользователь нажимает кнопку "💳 Оплатить"

**Что происходит:**
1. Бот проверяет, не оплачивал ли пользователь ранее
2. Показывает реквизиты карты и ID пользователя для связи с администратором

**Логи:**
```
INFO - User 123456789 requested payment details
```

---

### Шаг 3: Пользователь проверяет статус

**Действие:** Пользователь нажимает кнопку "📊 Мой статус" или отправляет `/status`

**Что происходит:**
1. Бот проверяет статусы оплаты и отправки материалов
2. Показывает сообщение "❌ СТАТУС ОПЛАТЫ: Не получена"

**Логи:**
```
INFO - User 123456789 checked status: paid=False, materials=False
```

---

## Сценарий 2: Пользователь оплатил

### Шаг 1: Администратор отмечает оплату

**Действие:** Администратор использует команду для отметки оплаты (будет реализовано в следующих задачах)

**Что происходит:**
1. В базе данных пользователю устанавливается `paid=1` и `paid_date`
2. Администратор получает подтверждение

---

### Шаг 2: Пользователь проверяет статус

**Действие:** Пользователь отправляет `/status`

**Что происходит:**
1. Бот показывает:
   - "✅ СТАТУС ОПЛАТЫ: Получена"
   - "⏳ СТАТУС МАТЕРИАЛОВ: В процессе обработки"

**Логи:**
```
INFO - User 123456789 checked status: paid=True, materials=False
```

---

### Шаг 3: Пользователь снова пытается оплатить

**Действие:** Пользователь нажимает "💳 Оплатить"

**Что происходит:**
1. Бот проверяет статус оплаты
2. Показывает сообщение "✅ Вы уже произвели оплату!"

**Логи:**
```
INFO - User 123456789 requested payment details
```

---

## Сценарий 4: Обработка ошибок

### Ошибка при добавлении пользователя

**Что происходит:**
1. Пользователь видит: "❌ Произошла ошибка. Попробуйте позже."
2. В логах записывается подробная информация об ошибке

**Логи:**
```
ERROR - Error in start handler: [detailed error message]
```

---

### Ошибка при проверке оплаты

**Что происходит:**
1. Пользователь видит: "❌ Произошла ошибка при обработке платежа."
2. В логах записывается информация об ошибке

**Логи:**
```
ERROR - Error in payment_button handler: [detailed error message]
```

## Примеры команд для тестирования

### Тестирование через Telegram

1. Найдите вашего бота в Telegram
2. Отправьте `/start` - должна появиться клавиатура
3. Нажмите "💳 Оплатить" - должны отобразиться реквизиты
4. Нажмите "📊 Мой статус" - должен отобразиться статус "Не получена"
5. Отправьте `/status` - должен быть тот же результат

### Тестирование через скрипт

```bash
python test_logic.py
```

Этот скрипт проверит:
- Инициализацию базы данных
- Добавление пользователя
- Проверку статусов
- Отметку оплаты
- Отметку отправки материалов
- Получение информации о пользователе

## Типичные проблемы и решения

### Бот не отвечает

**Причина:** Неверный токен или бот не запущен

**Решение:**
1. Проверьте `BOT_TOKEN` в `main.py`
2. Убедитесь, что бот запущен: `python main.py`
3. Проверьте логи: `tail -f logs/bot.log`

---

### Клавиатура не появляется

**Причина:** Ошибка в коде или проблема с Telegram API

**Решение:**
1. Проверьте логи на наличие ошибок
2. Попробуйте отправить `/start` снова
3. Перезапустите бота

---

### Ошибки в логах

**Причина:** Различные причины (проблемы с БД, сетью и т.д.)

**Решение:**
1. Прочитайте сообщение об ошибке в логах
2. Проверьте доступ к файлу `bot_data/bot.db`
3. Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`

---

## Мониторинг работы бота

### Просмотр логов в реальном времени

```bash
tail -f logs/bot.log
```

### Проверка базы данных

```bash
sqlite3 bot_data/bot.db "SELECT * FROM users;"
```

### Подсчет пользователей

```bash
sqlite3 bot_data/bot.db "SELECT COUNT(*) FROM users;"
```

### Подсчет оплативших пользователей

```bash
sqlite3 bot_data/bot.db "SELECT COUNT(*) FROM users WHERE paid = 1;"
```
