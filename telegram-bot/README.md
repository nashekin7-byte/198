# White Clinic Telegram Bot

Telegram-бот для стоматологической клиники White clinic с полной поддержкой всех функций.

## Описание

Бот предоставляет полную информацию о стоматологической клинике White clinic:
- Список услуг (хирургия, терапия, ортопедия, эстетика)
- Прайс-лист с ценами
- Полезные рекомендации по уходу за зубами
- Информация о врачах и клинике
- Запись на приём
- FAQ с ответами на частые вопросы

## Требования

- Python 3.8+
- `python-telegram-bot==21.4`
- `python-dotenv==1.0.0`

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Получите токен бота через [@BotFather](https://t.me/botfather) и добавьте его в файл `.env`:
```
BOT_TOKEN=ваш_токен_из_BotFather
```

## Запуск

```bash
python bot.py
```

## Функциональность

### Основные команды:
- `/start` - Главное меню
- `/help` - Справка по боту
- `/privacy` - Политика конфиденциальности

### Функции бота:
1. **Главное меню** - приветствие и навигация
2. **Наши услуги** - полный список услуг по категориям
3. **Прайс-лист** - цены на основные услуги
4. **Полезный гайд** - рекомендации по уходу за зубами
5. **О нас** - информация о клинике и врачах
6. **Записаться на приём** - контакты и способы записи
7. **Частые вопросы** - ответы на популярные вопросы

## PDF файлы (опционально)

### Прайс-лист
Вы можете добавить файл `price_list.pdf` в директорию бота, чтобы пользователи могли скачать полный прайс-лист. Если файл не найден, бот покажет примерные цены текстом.

### Гайд по уходу
Можно добавить файл `dental_guide.pdf` - полный гайд по уходу за зубами. Если файл не найден, бот покажет основные рекомендации текстом.
